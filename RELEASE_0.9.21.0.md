# Masar v0.9.21.0 — Flexible Manual Timetable Editing

- Manual move/swap and multi-lesson edits now warn rather than block on teacher/class overlaps, teacher availability, daily load, subject constraints and repetition.
- Invalid slots, missing entries, and locked lessons remain blocked.
- Explicit confirmation is required to save despite warnings.
- Recovery snapshot before changes, rollback on failed save, and manual conflict log accessible from timetable toolbar.
- Drag-and-drop follows the same warning-and-record behavior.
- This is a code-level release; full iPad Safari and end-to-end testing remain necessary.

# School Timetable v0.8

- واجهة تكليفات قائمة على المدرس مع البحث والفرز الأبجدي أو حسب التخصص والتصفية حسب حالة التكليف.
- فهرس المكلفين وغير المكلفين، ومجموع نصاب المدرس وتكليفاته.
- إضافة عدة تكليفات لمدرس واحد، بمواد وشعب من مراحل مختلفة، مع مراجعة قبل الحفظ.
- منع تكليف نفس المادة والشعبة لأكثر من مدرس من الواجهة الجديدة.
- استخدام حصص المادة من خطة المرحلة، مع السماح بتغييرها.
- تنسيق خلايا الجدول بحسب لون المرحلة، المادة بخط عريض واسم المدرس الأول والثاني أصغر.
- تحسين العرض على التابلت والهاتف، وإضافة رقم نسخة إلى روابط CSS وJS لمنع التخزين المؤقت القديم.
- الحفاظ على مفتاح localStorage السابق.

مهم: تعديل التكليفات يفرغ الجدول المولد القديم، لذلك صدّر نسخة احتياطية أولاً. اختبر الطباعة من المتصفح على الجهاز المستهدف.

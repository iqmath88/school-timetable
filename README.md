# School Timetable v0.4 — Generator Alpha

أول إصدار يولد جدولاً فعلياً.

المحرك:
- يطبق الحصص المثبتة أولاً.
- يمنع تعارض المدرس.
- يمنع تعارض الشعبة.
- يمنع وضع المدرس في وقت غير متاح.
- يحترم الحد الأعلى اليومي المضبوط للمدرس.
- يحقق العدد الأسبوعي لكل تكليف أو يعلن فشل الحل.
- يستخدم MRV + Backtracking للبحث.
- يفضل عدم تكرار المادة للشعبة في اليوم نفسه.
- يراعي الحصص المفضلة/غير المفضلة وتفضيل التتالي.
- يحاول تقليل فراغات المدرس وتوزيع الحمل.
- يعرض الجدول العام: الشعب أعمدة، والأيام والحصص صفوف.
- يحافظ على بيانات v0.1-v0.3.

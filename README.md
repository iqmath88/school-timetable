# School Timetable v0.5 — Optimization & Editing

أهم إضافات الإصدار:
- تعديل بيانات المدرس مع الحفاظ على ID والتكليفات والقيود.
- تعديل اسم المادة ولونها مع الحفاظ على العلاقات.
- تعديل التكليف من واجهة اختيار واضحة.
- أي تغيير بنيوي يمس الجدول يلغي الجدول المولد القديم حتى لا تبقى نتيجة غير متوافقة.
- مؤشر جودة للجدول من 100.
- إحصاء تكرار المادة في اليوم، فراغات المدرسين، والحصص غير المفضلة.
- استمرار Generator Alpha مع القيود الصلبة السابقة.

ملاحظة: التحسين متعدد المحاولات، النقل اليدوي الذكي، والقفل من داخل الجدول ستستمر في الإصدارات التالية بعد الاختبار الواقعي لهذه النسخة.

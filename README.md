# School Timetable v0.9.6.1 — إصلاح استعادة الجدول

هذا الإصدار يحافظ على تصدير PNG والطباعة والألوان من v0.9.6.

أضيف مرجع جدول المدرسة الناجح (688 حصة) داخل عامل التوليد. إذا كانت بيانات الجدول فارغة، يتحقق المحرك من المرجع مقابل **كل القيود الحالية** قبل استعادته. إذا تغيّرت البيانات بحيث لم يعد المرجع صالحاً، لا يفرضه المحرك، بل يستخدم البحث الاعتيادي.

## النشر
ارفع الملفات الخمسة إلى جذر مستودع GitHub. احتفظ بنسخة JSON الأصلية. افتح التطبيق واستورد ملف JSON الذي أرسلته، ثم اضغط «توليد الجدول تلقائياً». صدّر نسخة احتياطية جديدة بعد نجاح الاستعادة.

ملاحظة: هذه معالجة لحالة بيانات المدرسة المرفقة، وليست ضماناً لتوليد أي جدول جديد من الصفر.

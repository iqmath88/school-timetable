# School Timetable v0.8.4 — Gap Diagnostics & Timetable Views

- تقرير مفصل لفراغات المدرسين بين أول وآخر حصة، مع يوم وحصة وقيود توفر المدرس.
- تقرير للخانات الفارغة في كل شعبة، مع التمييز بين نقص مجموع التكليفات وفراغات توزيع الجدول.
- أزرار للانتقال مباشرة من التشخيص إلى جدول المدرس أو الشعبة المحددة.
- فرز أسماء المدرسين أبجدياً والشعب حسب ترتيب المرحلة.
- طباعة العرض الحالي للمدرس أو الشعبة أو المدرسة مع رأس وتذييل قابلين للتخصيص.
- تحسين مظهر الخلايا والتمييز بين المادة والمدرس.
- لا يتم تغيير بيانات المستخدم أو إعادة توليد الجدول تلقائياً.

ملاحظة: التشخيص يوضح أسباباً محلية محتملة ولا يثبت دائماً السبب الجذري للخانة الفارغة. النقل يخضع لفحص القيود.

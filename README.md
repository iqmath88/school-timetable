# School Timetable v0.5.1 — Editing UI Fix

إصدار تصحيحي لواجهة التعديل:
- زر ✏️ تعديل ظاهر بوضوح للمدرسين والمواد والتكليفات.
- عمود الإجراءات يبقى ظاهراً أثناء تمرير الجدول أفقياً على iPad والهاتف.
- تعديل المدرس داخل نافذة احترافية: الاسم، التخصص، الملاحظات.
- تعديل المادة داخل نافذة احترافية: الاسم واللون.
- لا يتغير ID عند التعديل، لذلك تبقى العلاقات والتكليفات والقيود.
- تعديل البيانات يلغي الجدول المولد القديم فقط عندما يلزم إعادة توليده.

# School Timetable v0.8.5 — إصلاح مراقبة التوليد

- إصلاح عداد العقد الصفري الظاهر عند توقف مراقب السلامة، مع تسجيل آخر إحصاءات وصلت من المحرك.
- تسجيل مراحل التحضير والتثبيت والبحث وإظهارها في الواجهة.
- تصحيح إيقاف المحرك وإعادة تهيئة زر التوليد بعد الإيقاف.
- زيادة مهلة المراقبة إلى 45 ثانية والمهلة الداخلية إلى 40 ثانية، مع الحفاظ على البيانات.
- تغيير إصدار ملف العامل لتفادي التخزين المؤقت في Safari.

لا يضمن هذا الإصدار إيجاد جدول كامل لكل مجموعة قيود؛ عند انتهاء المهلة ستظهر المرحلة الأخيرة بدلاً من رقم صفر مضلل.

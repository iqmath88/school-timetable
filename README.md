# School Timetable v0.8.2 — استقرار التوليد

- نقل البحث التراجعي إلى Web Worker مستقل، مع إيقاف التوليد دون فقد البيانات.
- مهلة 12 ثانية وحد أقصى 35,000 عقدة لكل محاولة. انتهاء المهلة **لا يعني** استحالة الجدول.
- تقدم دوري وتقرير سبب التوقف أو النجاح، مع الاحتفاظ بالجدول السابق حتى ينجح البديل.
- حافظ على المفتاح المحلي school-timetable-v01 وصيغة JSON القديمة.

## النشر
ارفع الملفات **الخمسة**: index.html, app.js, styles.css, generator-worker.js, README.md إلى جذر GitHub Pages. يجب رفع ملف العامل الجديد وإلا لن يبدأ التوليد. صدّر نسخة احتياطية قبل الاستبدال.

## القيود
هذه نسخة استقرار أولية وليست ضماناً لإيجاد حل لكل مدرسة. قد يتوقف البحث ضمن الحد المقرر، ويمكن حينها مراجعة القيود أو تحسين خوارزمية الجدولة لاحقاً. لم يُجر اختبار Safari فعلي.

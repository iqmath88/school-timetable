# School Timetable v0.9.4 — إصدار تجريبي

- طباعة الجدول المدرسي على صفحتين A3 أفقي: المتوسطة ثم الإعدادية، مع الحفاظ على جداول المدرسين والشعب.
- فصل الحد الأدنى للحصص في يوم التدريس عن الحد الأعلى. قيمة صفر تعني عدم فرض حد أدنى.
- يتحقق محرك التوليد من الحد الأدنى عند اكتمال الجدول، ويعطي أولوية لإكمال يوم المدرس الذي بدأ تدريسه.
- ما زال محرك البحث محدوداً بمهلة؛ لا يُعد انتهاء الوقت دليلاً على استحالة الجدول.
- احفظ نسخة احتياطية قبل التحديث، واختبر بيانات المدرسة كاملة قبل اعتماد الجدول.

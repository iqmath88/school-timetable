# School Timetable v0.2 — Constraints

الإصدار الثاني يضيف:
- توفر المدرس حسب اليوم والحصة.
- تعطيل يوم كامل للمدرس.
- الحصص المفضلة والحصص التي يفضل تجنبها.
- الحد الأعلى المفضل للحصص اليومية.
- تفضيل/تجنب الحصص المتتالية.
- تثبيت حصة مرتبطة بتكليف في يوم وحصة محددين.
- منع التثبيت عند تعارض المدرس أو الشعبة أو عدم توفر المدرس.
- ترقية تلقائية لبيانات v0.1 المخزنة محلياً دون حذفها.

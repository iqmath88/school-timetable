# Masar v0.9.19.5 — Live Duty Board

- Adds a dedicated daily-duty page to view each section's scheduled lesson for a selected day and period.
- Lists teachers with no scheduled lesson in the selected period and excludes teachers whose availability rules mark that slot unavailable.
- Adds summary counters and a printable period report.
- This is a day/period-selected view, not yet automatic clock-based period detection; lesson start/end times are not configured in the current data model.
- Validation performed: JavaScript syntax and ZIP integrity only. Browser/iPad end-to-end tests remain required.

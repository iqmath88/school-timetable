School Timetable v0.1 - Foundation

التشغيل:
افتح index.html مباشرة في المتصفح.

المزايا:
- إعداد اسم المدرسة والعام الدراسي.
- أيام الدوام وعدد حصص مختلف لكل يوم.
- ترتيب ثابت للمراحل من الأول إلى السادس.
- إضافة الشعب والمواد وألوان المواد.
- إضافة المدرسين فردياً أو جماعياً (Tab/CSV بسيط).
- إنشاء تكليفات مدرس + مادة + شعبة + حصص أسبوعية.
- منع التكرارات الأساسية ومنع حذف البيانات المرتبطة بتكليف.
- حفظ تلقائي محلياً عبر localStorage.
- تصدير/استيراد نسخة احتياطية JSON.
- مؤشر اكتمال بيانات تأسيس الجدول.

ملاحظة:
هذا الإصدار Foundation ولا يحتوي بعد على القيود أو فحص الجدوى أو توليد الجدول؛ هذه مراحل v0.2 وما بعدها.
